# Local Plotly dependency

- `plotly-4.0.0.min.js` is the minified Plotly.js distribution downloaded from the official Plotly CDN.
- Source URL: `https://cdn.plot.ly/plotly-4.0.0.min.js`
- SHA-256: `14461f3b4c91c8bb590a99d6d03c3fd031ca40eec07ebab79a5e3eac107cd7ca`
- `ch04-joint-marginal-plotly.js` recreates the Chapter 4 joint-density and marginal-density illustration with a standard independent bivariate normal model.

The build copies both JavaScript files into each language edition so that local files and GitHub Pages do not depend on a live CDN.
