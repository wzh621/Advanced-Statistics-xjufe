# Preface {-}

**School of Statistics and Data Science, Xinjiang University of Finance and Economics**

This is the English edition of the online handout for Advanced Statistics. The course begins with probability, then develops transformations and expectations, distribution families, random samples, data reduction, point estimation, hypothesis testing, interval estimation, and asymptotic theory.

The project is being migrated chapter by chapter. Chapter 1 is available as a complete, runnable Bookdown chapter based on the original Beamer sources. Chapters 2–10 currently contain structure placeholders only. Each major section is presented as a classroom-style teaching canvas while retaining the derivations and context expected from a reference handout.

## How to use this book {-}

- Mathematical notation is rendered with MathJax.
- Figures use `showtext_auto()` and automatic CJK-capable font detection.
- R examples run with project-relative paths.
- The source LaTeX, code, figures, and textbook are retained in the project and copied under `legacy/`.
- Source ambiguities and necessary compatibility edits are documented in `migration_notes.md`.
- Use the language link in the sidebar to switch to the Chinese edition.
